# Student Attendance Management System

This is a Streamlit-based Attendance Management App for University students by batch, section, and subject.

- ✅ Teacher-based password login
- ✅ HOD special access for downloading attendance
- ✅ Live updating Excel files
- ✅ University logo and clean design

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
